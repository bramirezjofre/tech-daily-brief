OpenAI anunció que adquirirá Pierre Computer Company, la compañía detrás de **Code Storage** y de varias herramientas de código abierto para trabajar con repositorios Git. La operación busca ampliar las capacidades de Codex para construir, entender y revisar software en flujos donde los agentes trabajan en paralelo.

## Qué aporta Pierre

OpenAI señala que el equipo de Pierre está detrás de **Trees** y **Diffs**, bibliotecas que ya utiliza en la aplicación Codex. Trees permite navegar rápidamente por los archivos de un proyecto y Diffs facilita inspeccionar los cambios. La compañía también menciona Highlights, un resaltador de sintaxis diseñado para actualizarse mientras una persona escribe o un agente transmite código.

Pierre creó además Code Storage, un servicio para que las aplicaciones almacenen código y sigan su historial con Git. Diffs incluye un modo de edición que permite corregir una línea directamente desde la vista de diferencias.

La tesis de OpenAI es que los sistemas alrededor de Git deben evolucionar cuando una parte cada vez mayor del trabajo se ejecuta en paralelo. En ese escenario, crear una rama, revisar cambios, resolver conflictos y conservar el contexto de las decisiones deja de ser una secuencia exclusivamente manual.

## Cómo encaja en Codex

OpenAI afirma que quiere conectar el código que una empresa publica con las decisiones que toman sus personas y agentes. La integración no se presenta como un reemplazo inmediato de Git, sino como una ampliación de las herramientas de colaboración y revisión alrededor del control de versiones.

La empresa también relaciona la compra con Pando, su backend compatible con Git para escalar el desarrollo interno. La combinación apunta a dos capas distintas: Pando aborda la escala del almacenamiento y la operación interna de Git, mientras el equipo de Pierre aporta interfaces, bibliotecas y servicios para navegar y revisar cambios.

Para los equipos de desarrollo, el valor potencial está en reducir el costo de revisar grandes volúmenes de cambios generados por agentes. Una vista de diferencias rápida, la edición contextual y un historial que conserve decisiones pueden ayudar a que el aumento de velocidad no se convierta en una pérdida de trazabilidad.

## Condiciones y límites

OpenAI dice que los proyectos de código abierto de Pierre continuarán siendo abiertos y que seguirá contribuyendo a ellos. Los clientes podrán continuar usando Code Storage después del cierre mientras la empresa trabaja para llevar sus funciones a Codex.

La adquisición todavía está sujeta a condiciones habituales, incluidas aprobaciones regulatorias. Hasta que se complete, OpenAI y Pierre seguirán siendo compañías separadas e independientes. Por eso, todavía no hay un calendario confirmado para una integración técnica ni detalles sobre cambios de precios, APIs o disponibilidad.

La noticia tampoco demuestra por sí sola que los agentes puedan producir software de mayor calidad. El cuello de botella puede desplazarse desde escribir código hacia revisar, probar y decidir qué cambios se aceptan. La oportunidad para Codex está en hacer esas etapas más observables y reversibles, no solo en generar más líneas por minuto.
