La carrera por el mejor agente de código sigue on fire, y ahora xAI (los cabros de Elon Musk) se tiran a la piscina con **Grok Build**. Se trata de un agente de terminal diseñado específicamente para devs, y viene con el motor del recién lanzado **Grok 4.5**.

Lo interesante de Grok Build es su enfoque: antes de tirar líneas de código a lo loco, se toma el tiempo de planificar el trabajo. Y no solo eso, sino que es capaz de levantar múltiples sub-agentes en paralelo para resolver distintas tareas al mismo tiempo. Es decir, mientras uno te arregla el CSS, otro te puede estar levantando la base de datos o arreglando tests. 

Por si fuera poco, ya hay integraciones dando vueltas (como con Composio) que le permiten conectarse a herramientas externas usando MCP. Grok 4.5 parece estar posicionado de manera muy competitiva en la guerra de modelos contra OpenAI y Anthropic. ¡A probar se ha dicho!
